# Nave — Audit Findings Ledger

Source of truth: consolidated findings from the **Full Product Audit** plan
(`full_product_audit_1d29c810`). This is a living ledger; remediation happens in
the plan's phases. Each finding carries an owning plan todo id, a default status
of **in progress**, and a concrete test-to-prove-fixed.

- **Status legend:** `in progress` (default), `fixed`, `verified`, `wontfix`.
- **Areas:** Homepage, Dashboard, Agents, Assets, Governance, Constitution,
  Tokens, Settings, 4-Agent System, Security, Contracts, Backend/Edge, Infra/CI.
- Line numbers are cited where independently verified read-only during Phase 0;
  unverified locations cite the file path from the plan.

> Verdict context: the core money path is fundamentally sound — signing
> authority is deterministic (model is advisory only), guardrails fail-closed,
> the 3-of-3 + review-window pipeline is enforced on-chain, fee math is
> `u128`-safe and floor-rounds toward the treasury, and 36 Rust unit tests pass.
> Risk concentrates in (a) oracle/NAV safety assumptions (Medium, phase2), (b)
> cosmetic/mocked UI controls that misrepresent on-chain state (phase3), and
> (c) dead/unused surface area. **Update 2026-06-30:** the Critical RLS bug
> (C1) and all 8 High findings (H1-H8) are now fixed/verified — see each row
> and the corrected Deployed-state snapshot below. This ledger's earlier
> "confirmed live" language for C1/H1/H2 was based on an incomplete migration
> scan and is corrected in place rather than deleted, for traceability.
